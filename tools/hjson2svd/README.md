# hjson2svd

Python tool to convert hardware description file hjson into svd files.

HJSON format is described in [hjson](https://github.com/lowRISC/opentitan/blob/master/doc/contributing/hw/comportability/README.md#configuration-description-hjson).

SVD format is described in [CMSIS-SVD](https://arm-software.github.io/CMSIS_5/SVD/html/index.html).
